Team Member Showcasing

 About the Project

Team Member Showcasing is a website I created to display team members, their roles, and a little information about each person. The aim of this project is to practise building a website using HTML, CSS, and JavaScript while learning how to work with an API.

Features

- Displays team members in cards.
- Shows information about each team member.
- Uses JSON Server to store team member data.
- Uses JavaScript to fetch and manage data.
- Has a simple and user-friendly design.
- Includes tests for checking parts of the application.

Technologies Used

- HTML
- CSS
- JavaScript
- JSON Server
- Git and GitHub
- Figma

 Project Setup

To run the project on your computer, follow these steps.

1. Clone the repository

git clone https://github.com/nimcomuxidinaxmed7-cmd/team-member-showcasing.git

2. Open the project folder


cd team-member-showcasing

 3. Install the dependencies

npm install


 4. Start JSON Server

npm start

Keep the terminal running while using the API.

5. Open the website

Open index.html using the Live Server extension in VS Code.
 Running Tests

To run the project tests, use:

npm test

To check test coverage, use:

bash
npm run coverage


The project aims to achieve at least 50% JavaScript test coverage.
